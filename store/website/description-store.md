# ImgRalph — description Store 3

## FR

ImgRalph transforme le détourage en un geste unique. Déposez une image n’importe où sur la page : le traitement ouvre un écran de progression, puis le pourcentage devient « Télécharger ». Vous récupérez un PNG transparent, recadré automatiquement autour du sujet avec une bordure d’un pixel.

Choisissez remove.bg via API ou le moteur local du navigateur, sélectionnez u2net, u2netp ou le modèle dédié aux personnes, puis ajustez le cœur de détourage de -50 à 200.

## EN

ImgRalph turns background removal into a single gesture. Drop an image anywhere on the page: processing opens a fullscreen progress view, then the percentage becomes “Download.” You get a transparent PNG, automatically cropped around the subject with a one-pixel border.

Choose remove.bg through its API or the browser’s local engine, select u2net, u2netp, or the human-segmentation model, then adjust the cutout core from -50 to 200.
