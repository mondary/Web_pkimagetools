## Description longue

### FR

**ImgRalph** détourre vos images directement dans le navigateur, sans upload : le modèle ONNX (`rembg-web`) tourne côté client via WebAssembly, supprime l'arrière-plan, recadre automatiquement au contenu avec une bordure de 1 px et propose le PNG en téléchargement en un clic.

#### ✨ Fonctionnalités clés
- **Glisser-déposer ou sélection** — PNG/JPG/WEBP, aucune installation
- **Détourage local** — `@bunnio/rembg-web` + ONNX Runtime dans le navigateur
- **Recadrage automatique** — au contenu, bordure 1 px
- **Barre de progression plein écran** — suivi visuel du traitement
- **Téléchargement en un clic** — récupération directe du PNG détouré
- **Variante tolérance** — curseur alpha (0-255) pour ajuster le seuil de recadrage
- **Statique** — aucun build, fichiers HTML/CSS/JS servis tels quels

### EN

**ImgRalph** removes image backgrounds right in the browser, with no upload: the ONNX model (`rembg-web`) runs client-side via WebAssembly, strips the background, auto-crops to the content with a 1-px border and offers the PNG for download in one click.

#### ✨ Key features
- **Drag & drop or file picker** — PNG/JPG/WEBP, nothing to install
- **Local cutout** — `@bunnio/rembg-web` + ONNX Runtime in the browser
- **Auto-crop** — to the content, 1-px border
- **Full-screen progress bar** — visual tracking of the processing
- **One-click download** — get the cut-out PNG directly
- **Tolerance variant** — alpha slider (0-255) to tune the crop threshold
- **Static** — no build, HTML/CSS/JS files served as-is
